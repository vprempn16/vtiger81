================================================================================
WHATSAPP MODULE INSTALLATION & WORKFLOW GUIDE
================================================================================

1. INSTALLATION INSTRUCTIONS
--------------------------------------------------------------------------------
- Go to **Settings** -> **CRM Settings** -> **Module Manager**.
- Click on **Install from Zip** button at the top right.
- Upload the `Whatsapp.zip` file.
- Follow the installation prompts and click **Finish**.

*Note: The system automatically runs `postInstall` scripts to:*
- Create necessary database tables (Channels, Templates, Media).
- Register WebService entities (`vtiger_ws_entity`).
- Configure entity names setup (`vtiger_entityname`).
- Enable Setup links and backend cron headers structure links setup.


2. INITIAL CONFIGURATION & SETUP
--------------------------------------------------------------------------------
1. Go to **Settings** -> **Other Settings** -> **WhatsApp Channels Setup**.
2. Click **Add Channel** to register your Meta WhatsApp Business API:
   - **Name**: Channel Identification Label.
   - **App ID** & **App Secret**: Meta app values.
   - **Phone Number ID**: ID from Meta dashboard numbers config.
   - **Business ID**: Meta Business Manager Identification code.
   - **Access Token**: Recommended to use a Permanent System User Token.
3. Ensure the channel is marked as **Active**.
4. Click **Sync Templates** to pull and cache your Meta pre-approved templates directly into the CRM interface.
5. **Map Templates**: After syncing, click the **Map** icon/button next to a template to link its variables to corresponding CRM module fields. This mapping is necessary so variables populate correctly when sending a template message via the **Send WhatsApp** modal or Workflows.


3. META WEBHOOK CONFIGURATION
--------------------------------------------------------------------------------
To receive incoming messages and delivery statuses, configure the Webhook inside your Meta Developers Dashboard:

- **Callback URL**: `https://<your-crm-domain>/whatsapp_webhook.php`
- **Verify Token**: `atompen_wa_verify_token`
- **WebHook Subscriptions Fields**: Subscribe to **`messages`**.


4. OPERATIONAL WORKFLOW & FLOW LOGIC
--------------------------------------------------------------------------------

A. Manual Messaging (Detail View Modal)
   - Navigate to **Contacts** or **Leads** detail views records.
   - Click the **Send WhatsApp** button.
   - Select the number (Trigger handles automatic Clean checking support format validation).
   - If the number fails to incorporate international Country codes (>10 length digits criteria checks), a warning notification prevents enabling continuous dispatching.
   - Support lists Template selection headers variable binding forms inputs dynamically.

B. Automated Messaging (Workflows Actions)
   - Navigate to **Settings** -> **Workflows**.
   - Select action type: **Send Whatsapp Message**.
   - Create template bindings headers setups mapping CRM fields identifiers dynamic codes layouts placements.
   - Recipient fields UI displays a warning advise asserting country codes length inclusion requirements.

Logs debug trails outputs writing structures directories: `storage/wa_validation.log`.
